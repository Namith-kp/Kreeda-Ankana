# App Screenshots Directory

Please drop your premium, high-resolution app screenshots in this folder to automatically populate the `README.md` cinematic gallery!

Make sure you rename your image files to exactly match these filenames, or update the HTML `<img>` source tags inside the main `README.md` to point to your new file names.

### Required Files:
1. `1_home.png` -> Home Dashboard
2. `2_scores.png` -> Live Score Wall
3. `3_tournaments.png` -> Tournament Brackets
4. `4_squad.png` -> Squad Builder
5. `5_booking.png` -> Turf Booking
6. `6_challenges.png` -> Challenges & Events
7. `7_matchmaking.png` -> Free Agent Matcher
8. `8_profile.png` -> Player Profile

_Tip: For the best visual alignment in the table, try to ensure all screenshots have the exact same aspect ratio and resolution (e.g., 1080x2400)._
